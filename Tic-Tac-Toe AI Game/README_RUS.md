# Крестики-нолики — API с компьютерным соперником

REST API на Flask для игры в крестики-нолики против компьютера, использующего алгоритм «Минимакс».

Проект посвящён многослойной архитектуре, внедрению зависимостей, реализации игровой логики и управлению несколькими играми через HTTP API.

## Возможности

- Создание игр с уникальными UUID.
- Передача ходов игрока в виде обновлённого игрового поля.
- Генерация ходов компьютера с помощью алгоритма «Минимакс».
- Определение победы и ничьей.
- Проверка сохранности ранее поставленных отметок компьютера.
- Хранение нескольких игр в памяти.
- Разделение обработки запросов, бизнес-логики и доступа к данным.

## Технологии

- **Python 3**
- **Flask** — HTTP-маршрутизация и JSON-ответы.
- **Минимакс** — оценка возможных ходов.
- **threading.Lock** — синхронизация чтения и записи в репозитории.
- **uuid** — генерация идентификаторов игр.

## Архитектура

Приложение разделено на четыре слоя:

| Слой | Ответственность |
| --- | --- |
| `web` | HTTP-маршруты, модели запросов и ответов, преобразование моделей между слоями web и domain. |
| `domain` | Игровые модели, интерфейс сервиса, проверка ходов и алгоритм «Минимакс». |
| `datasource` | Модели хранения, репозиторий в памяти и преобразование моделей между слоями datasource и domain. |
| `di` | Собственный контейнер, который создаёт и повторно использует экземпляры репозитория и сервиса. |

Отдельные модели и мапперы позволяют отделить игровую логику от обработки HTTP-запросов и деталей хранения данных.

## Установка

Требуются Python 3 и `pip`.

Установите Flask из корня проекта:

```bash
python -m pip install Flask
```

## Запуск приложения

Выполните из корня проекта:

```bash
cd src
python -m web.route.controller
```

Запускайте приложение как модуль из каталога `src`, чтобы импорты между слоями проекта работали корректно.

Сервер разработки запускается по адресу `http://127.0.0.1:5000` с включённым режимом отладки.

Проект предоставляет HTTP API. Для отправки запросов можно использовать API-клиент, например Postman.

## Представление игрового поля

Игровое поле представлено целочисленной матрицей размером 3×3:

| Значение | Описание |
| --- | --- |
| `0` | Пустая клетка |
| `1` | Отметка игрока |
| `2` | Отметка компьютера |

Пример:

```json
[
  [1, 0, 0],
  [0, 2, 0],
  [0, 0, 0]
]
```

## Методы API

### Создание игры

```http
POST /game/new
```

Создаёт новую игру с пустым полем. Тело запроса не требуется.

Пример ответа:

```json
{
  "uuid": "123e4567-e89b-42d3-a456-426614174000",
  "field": [
    [0, 0, 0],
    [0, 0, 0],
    [0, 0, 0]
  ]
}
```

UUID приведён для примера. В последующих запросах используйте идентификатор, полученный от сервера.

### Выполнение хода

```http
POST /game/{uuid}
Content-Type: application/json
```

Передайте полное игровое поле после добавления отметки игрока. Сохраните все отметки из предыдущего ответа сервера.

Пример первого хода:

```json
{
  "field": [
    [1, 0, 0],
    [0, 0, 0],
    [0, 0, 0]
  ]
}
```

Сервер проверяет переданное поле, выполняет ход компьютера, сохраняет обновлённую игру и возвращает:

| Поле | Описание |
| --- | --- |
| `uuid` | Идентификатор игры. |
| `field` | Игровое поле после хода компьютера. |
| `status` | `true`, если игра завершена; иначе `false`. |

Используйте полученное поле как основу для следующего хода игрока.

### Ответы с ошибками

Для явно обработанных ошибок API возвращает поле `error`.

| HTTP-статус | Описание |
| --- | --- |
| `400` | Ход изменяет ранее поставленную отметку компьютера. |
| `404` | Игра с указанным UUID не найдена. |

Пример:

```json
{
  "error": "Неверный ход"
}
```

Сообщения об ошибках возвращаются на русском языке.

## Хранение игр

Игры хранятся в словаре в памяти внутри репозитория. Операции чтения и записи защищены с помощью `threading.Lock`.

Каждая игра имеет собственный UUID, что позволяет приложению хранить несколько независимых игр.

## Ограничения текущей версии

- При перезапуске сервера игры теряются. Хранилище не является общим для нескольких серверных процессов.
- Проверка поля защищает ранее поставленные отметки компьютера. Размеры поля, значения клеток, количество ходов и запросы после завершения игры пока обрабатываются не полностью.
- Ответ сообщает о завершении игры, но не указывает отдельно победителя или ничью.
