# Асинхронность и многопроцессность на Python

Пет-проект из двух консольных приложений: симулятора экзамена и загрузчика изображений. Проект создан для практики работы с несколькими процессами, асинхронными задачами, общими данными и сетевыми запросами.

## Технологии

- **Python 3**
- **multiprocessing** — параллельная работа экзаменаторов, обмен данными через `Manager` и синхронизация через `Lock`.
- **asyncio** — создание асинхронных задач загрузки.
- **aiohttp** — HTTP-запросы.
- **PrettyTable** — отображение результатов в консольных таблицах.

## 1. Симулятор экзамена

Приложение моделирует экзамен с общей очередью студентов и несколькими экзаменаторами. Для каждого экзаменатора запускается отдельный процесс.

### Возможности

- Чтение студентов, экзаменаторов и вопросов из текстовых файлов.
- Выбор трёх случайных вопросов для каждого студента.
- Вероятностный выбор ответов с использованием золотого сечения.
- Учёт настроения экзаменатора при выставлении результата.
- Моделирование времени сдачи и обеденных перерывов.
- Обновление консольных таблиц со статусами студентов и статистикой экзаменаторов.
- Формирование итогового отчёта.

После завершения программа выводит результаты студентов, статистику экзаменаторов, общую продолжительность экзамена, лучших студентов и экзаменаторов, наиболее успешные вопросы и общий итог.

## 2. Загрузчик изображений

Приложение получает ссылки из консоли и сохраняет изображения по указанному пути. Для загрузок используются задачи `asyncio` и HTTP-клиент `aiohttp`.

### Возможности

- Ввод пути сохранения с проверкой его существования и прав на запись.
- Последовательный ввод нескольких ссылок.
- Создание задач для загрузки изображений.
- Определение расширения файла по заголовку `Content-Type`.
- Генерация случайных имён файлов при сохранении в каталог.
- Ожидание созданных задач после завершения ввода.
- Вывод таблицы ссылок со статусами предварительных HTTP-запросов.

```bash
python -m pip install aiohttp prettytable
```

## Запуск симулятора экзамена

Запускайте приложение из каталога `src/exercise1`: программа ищет входные файлы в текущей рабочей папке.

```bash
cd src/exercise1
python task_1.py
```

### Входные данные

Все файлы должны быть сохранены в кодировке UTF-8.

В `examiners.txt` и `students.txt` каждая строка содержит имя и обозначение пола: `М` или `Ж`.

Пример `examiners.txt`:

```text
Степан М
Дарья Ж
Михаил М
```

Пример `students.txt`:

```text
Петр М
Сергей М
Варвара Ж
```

В `questions.txt` каждый вопрос располагается на отдельной строке. Для работы программы необходимо минимум три вопроса.

```text
Там стоит стол
Человек собаке друг
Солнечные затмения влияют на людей
Программирование интересное занятие
```

Результаты могут отличаться при каждом запуске: вопросы, ответы и настроение экзаменаторов выбираются случайно.

## Запуск загрузчика изображений

Выполните из корня проекта:

```bash
mkdir images
python src/exercise2/task_2.py
```

1. Укажите существующий каталог для сохранения, например `./images`.
2. Вводите ссылки на изображения по одной.
3. Отправьте пустую строку, чтобы завершить ввод.
4. Дождитесь завершения задач и вывода таблицы.

### Ограничения текущей версии

Обычный консольный `input()` может приостанавливать выполнение асинхронных задач во время ожидания ввода. Сетевые ошибки и ошибки записи пока могут прервать программу.

Статус «Успех» отражает ответ сервера при предварительном запросе и не гарантирует сохранение файла.
